고등학교 시험 배점 추천기

선택형·서답형 문항 수와 배점 예시를 입력하면 유형별로 독립적인 배점안을 추천해 드립니다.

시험 정보 입력

선택형 난이도별 문항 수

선택형 자동 합계: 20 / 20

서답형을 켜면 총점 100점 안에서 선택형과 서답형 목표 점수를 나눠 계산합니다.

선택형·서답형 총점: 100.0 / 100.0

세부 옵션

선택형 난이도별 배점 종류 수

각 값은 해당 난이도 문항 수 이하여야 합니다. 문항 내 배점 간격은 0.1점 고정입니다.

서답형 정보 입력

서답형 난이도별 문항 수

서답형 자동 합계: 3 / 3

서답형 세부 옵션

서답형 난이도별 배점 종류 수

서답형 난이도와 배점은 선택형과 별도로 계산되며, 추천안은 정수 배점과 난이도 간 1점 간격을 기본으로 합니다.

고등학교 시험에서는 동점을 줄이기 위해 문항마다 차등 배점을 씁니다. 배점 예시는 기준점이며, 아래 추천안은 입력한 배점 종류 수를 유지한 채 배점별 문항 수 분포를 조정합니다.

추천안 비교 (3가지)

마음에 드는 안을 선택한 뒤, 유형·문항별 배점을 직접 수정할 수 있습니다.
